# Chelsea Net Spend Dashboard

An interactive dashboard analyzing Chelsea FC's transfer net spend, player sales revenue, and club financials since the BlueCo / Clearlake Capital takeover (May 2022), including the ongoing 2026/27 transfer window.

## Contents

- **Overview & Revenue** — season-by-season spend vs. sales income, biggest signings/sales, club financial results (revenue and pre-tax profit/loss)
- **Player Sales vs. Other Clubs** — comparison of Chelsea's player-trading income and net spend against Premier League rivals
- **Detailed Report** — full narrative writeup, methodology, caveats, and sources

## Viewing

Open `index.html` directly in a browser, or enable GitHub Pages for this repository (Settings → Pages → deploy from branch) to get a hosted link.

Figures are best-public-estimates compiled from multiple sports/finance outlets (see Sources in the Detailed Report tab) — not official audited transfer data. Last updated 25 July 2026, with the 2026/27 transfer window still open.
